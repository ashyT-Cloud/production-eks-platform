# Production Kubernetes Platform on AWS

A production-grade Kubernetes platform built on Amazon EKS using Infrastructure as Code, GitOps, and Observability best practices.

---

## Project Goal

This project demonstrates how to design, provision, deploy, and operate a production-ready Kubernetes platform on AWS using modern DevOps practices.

The entire platform is built following real-world engineering workflows, including feature branching, Infrastructure as Code, GitOps, CI/CD, monitoring, logging, and automated deployments.

---

## Planned Architecture

Terraform
→ Amazon VPC
→ Amazon EKS
→ Managed Node Groups
→ IAM Roles for Service Accounts (IRSA)
→ AWS Load Balancer Controller
→ Amazon ECR
→ Helm
→ Argo CD (GitOps)
→ FitTrack Application
→ Horizontal Pod Autoscaler
→ Prometheus
→ Grafana
→ Fluent Bit
→ Amazon CloudWatch
